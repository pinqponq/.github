## pinqloq

A centralized logging SDK and real-time dashboard for .NET applications.
One line of ASP.NET Core middleware logs every HTTP request automatically.
Custom events, exceptions, and client-side events (mobile, browser) flow
through the same backend SDK — no separate infrastructure required.

## rindle

A camera-first memory app for couples. Rindle opens straight to the camera,
then a quick triage step keeps only the best shots and moves them into a
private shared vault for the two of you. Your moments map onto every trip as a
route, physical tickets scan into digital memory cards, and the app turns it
all into automatic collages and videos. A daily question keeps you both coming
back to learn more about each other.
